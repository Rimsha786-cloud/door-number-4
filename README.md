## Deploying to Vercel

1. Push this folder to a GitHub repository, then import it in Vercel (or run `npx vercel` inside the folder).
2. `vercel.json` already sets the install and build commands (the build targets Vercel through `NITRO_PRESET=vercel`). Leave the framework preset as "Other".
3. In Project Settings → Environment Variables add `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY` (see `.env.example`) so the enquiry forms can save. Without them the forms show a "please email us" message.
4. Menu PDFs go in `public/menus/` and are listed in `src/assets/documents.json`.
